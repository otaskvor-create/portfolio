Proconom App — construction management platform

Proconom Desktop App helps construction teams manage project documentation, construction data and collaboration in one centralised place, through an integrated CDE and DMS. My contribution focused on expanding its established design system with new features and screens.

Problem

The main challenge was expanding a complex desktop application with new screens and features while working inside an already-established design system. Each new feature had to use existing components to keep the interface consistent and easy to use.

Approach

During my involvement, I expanded the application with several new screens and workflows, including the purchasing process and shopping cart, while also improving existing screens and user flows.

Work within the rules

Every new screen had to fit naturally into the existing design system, reusing established components and patterns while maintaining consistency across the product.

Collaborative decisions

Design decisions were discussed closely with other designers and project managers, balancing different perspectives, technical constraints, and the needs of existing users.

Solution

Two examples show the scope of the work: a redesigned dashboard that finally surfaces everything a project manager needs at a glance, and a brand-new digital purchasing flow for a process that used to be entirely manual.

  • A rebuilt dashboard surfacing workflow status, budget changes, invoices, documents and a live map / 3D model in a single view
  • A new three-step purchasing flow — choose a database, select sections, review a summary — replacing an entirely manual ordering process
  • Beyond these key flows, I designed many additional screens, made smaller improvements across the product, and contributed to the design system itself
