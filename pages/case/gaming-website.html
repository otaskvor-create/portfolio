SkinRaters — gaming review website

SkinRaters helps players navigate external marketplaces for buying, selling and trading virtual in-game items, comparing them on trust, service quality, features and overall rating. I built it entirely solo — from idea and brand to UI/UX, content, a hand-coded front end and SEO.

Problem

At the start, there was no existing product and no defined brief — the whole concept had to be built from zero. That meant coming up with a name and visual identity, defining the platform's core purpose, analysing the competitive landscape, and designing a content structure that would actually deliver value to visitors.

The scope was significant on its own: beyond UI/UX, the project needed written content, a fully hand-coded front end, a static site connected to a WordPress backend for the blog, and deployment plus indexing — all built solo in spare time over roughly eight to ten weeks.

Design process

The project started with competitive and content analysis, then moved through UI/UX design, hand-coded development, and finally implementation with SEO.

Competitive & content analysis

Analysed existing marketplace-comparison sites, encyclopedias and communities, comparing content structure, rating approach, UI quality and trust signals. Many existing sites had lots of information but no consistent rating criteria — an opening for a clearer, more trustworthy comparison.

UI/UX design

Wireframes progressed from low- to high-fidelity, centred on reusable comparison cards with a clear rating system. I designed the blog and content pages alongside the brand, and tuned copy for both clarity and target keywords.

From wireframe to high fidelity prototype

Development

The static front end was hand-coded in HTML, CSS and JavaScript with no page builder or template, giving full control over code structure, responsive behaviour and visual accuracy. WordPress was used only as a content backend for the blog.

Implementation & SEO

After launch, I connected the site to search engines and handled on-page SEO — titles, heading structure, meta descriptions, image alt text and URLs — along with an initial keyword and backlink strategy.

UI development

Result

The result is a responsive platform comparing external marketplaces across five competitive games, with a dedicated review page per service covering its features, advantages, disadvantages and overall trust rating.

  • Consistent rating cards comparing trust, features and service quality across marketplaces
  • A dedicated review page per platform, with pros, cons and an overall score
  • A content/blog section building topical authority and long-term organic traffic
  • A hand-coded static front end, with WordPress used only for the blog backend
  • Fully responsive, independent of third-party page builders or templates
