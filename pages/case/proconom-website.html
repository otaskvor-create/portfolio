Proconom — company presentation website

Proconom's website hadn't kept up with the company behind it. I led a full redesign — a new visual identity, reorganised content, and several new features — across the entire multi-page site.

Problem

The main challenge was migrating the existing content into a completely fresh design. The original site had grown quite large over the years, so it took real work to land on a style that would still feel modern and user-friendly across every single page.

Research & process

The whole process started with an analysis of the existing website and a straightforward question: what should the new one contain, and what shouldn't it?

Stakeholder meetings

Several short meetings with the team clarified the direction before a single sketch was drawn.

Sketches

Simple sketches based on those meetings mapped out the direction I wanted the project to take.

Wireframes

Dozens of valid layout options made this stage genuinely hard — I didn't lock in the best one until the very last moment.

UI design

Based on the approved wireframes, I spent the following weeks designing the final UI for all pages.

Wireframes vs final design

Development

I hand-coded the static front end in HTML, CSS and JavaScript with no page builder or template, giving full control over code structure, responsive behaviour and visual accuracy.

UI development

Solution

The result was a fully responsive, modern website with a significantly better interface and experience. The previous site crammed too much information into too little space, so I cut the text down to what actually mattered and wrapped it in a design both managers and the team were happy with.

  • A full visual identity built around the company's red-and-orange gradient colours
  • A consistent, reusable component system across every page, avoiding repeated one-off elements
  • End-to-end execution: from first designs to independently developing a fully responsive website
Color palette

Outcome

I programmed the site myself, which let me enrich the final product with improvements like animations and micro-interactions that never made it into the prototypes — one of the advantages of being designer and developer in one. After a round of consultation and testing with project managers, the project was handed to development to replace the outdated site.
